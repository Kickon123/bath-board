# 館内マップ（facility-map）一式

このフォルダだけで館内マップ画面を利用できます。

## 構成
```
facility-map.html      ← 本体（CSS・JS内蔵）
maps/floor1〜5.jpg      ← 各階のフロア画像（必須）
vendor/pannellum.*      ← 360°ビューア用（360°スポットを使う場合のみ）
room_picture/<部屋>/    ← 客室写真（※サーバー併用時のみ表示）
```

## 使い方

### A. 地図を見るだけ（サーバー不要）
`facility-map.html` を**ダブルクリック**でブラウザに開くだけ。
- 5フロアのアイソメ表示・タップで正面表示まで動作します。
- `maps/` フォルダを必ず一緒に置いてください（地図画像の参照先）。

### B. 別ページに埋め込む
```html
<iframe src="facility-map.html"
        style="width:100%;height:100vh;border:none;"></iframe>
```

## 注意（客室写真機能について）
部屋タップで出る「客室写真」は `/api/room-photos/<部屋番号>` を呼ぶため、
**Nodeサーバー（元の QR/server.js）が動いている環境**でのみ表示されます。
ファイルを開くだけ（file://）の場合、地図は表示されますが客室写真は出ません。
その場合は `room_picture/` は使われません。

## フォルダごと移動・コピーする場合
中の相対パス（`maps/` `vendor/`）を保つため、**フォルダ単位**で移動してください。
個別ファイルだけ移すとリンクが切れます。
